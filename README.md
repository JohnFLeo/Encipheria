# Encipheria 
**Encipheria** is a C++ cryptography learning project that explores the *history of encryption* by implementing classical and modern ciphers from scratch.
From ancient substitution ciphers to public-key cryptography, this project aims to "dig up" and reconstruct encryption methods like an archaeologist of code.
Encipheria is not only a coding project: it is also a structured learning journal.

## Disclaimer

This project is **strictly educational**.

It is NOT: 
- Secure for real-world encryption
- Resistant to attacks or side channels
- Suitable for production systems

It IS:
- A C++ experimentation playground
- A collection of Cyphers with explanation
- A learning project combining implementation and documentation (Wiki included as an integral part of the project)
